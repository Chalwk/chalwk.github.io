## Common Rules

The following rules apply to the **Chalwk - Code & Chill** Discord server and
to any GitHub discussions, issues, or pull requests connected to my repositories.

| Rule                                             | Description                                                                                                                                                                      |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No Offensive Language or Content**             | Avoid offensive or inappropriate language, usernames, or profile pictures on Discord or GitHub.                                                                                  |
| **No Trolling or Harassment**                    | Do not troll, harass, or intentionally upset others on any platform.                                                                                                             |
| **No Impersonation**                             | Do not impersonate community members, moderators, contributors, or the server itself.                                                                                            |
| **No Scamming or Misleading People**             | Be honest about what a script does, what it costs, and what it can't do. Do not mislead people about paid work, commissions, or services.                                        |
| **Keep Personal Information Private**            | Do not share sensitive information about yourself or others.                                                                                                                     |
| **No Controversial Topics**                      | Avoid drama, politics, and religion in public channels.                                                                                                                          |
| **No Spamming or Advertising**                   | Do not disrupt conversations with irrelevant messages, mention spam, ads, or unsolicited Discord invite links.                                                                   |
| **Respect Moderator Instructions**               | Follow moderator instructions in channels, voice, DMs, and events.                                                                                                               |
| **No Bypassing Filters**                         | Do not circumvent chat filters or automated moderation.                                                                                                                          |
| **Respect Personal Boundaries**                  | Do not invade privacy via DMs or press people for personal details.                                                                                                              |
| **No Malicious Activities**                      | Do not distribute malware, share harmful links, or attempt to compromise other members.                                                                                          |
| **No Disrupting Server Performance**             | Avoid actions that cause disruption, such as raid coordination, mass pings, or bot abuse.                                                                                        |
| **No Exploiting Bots or Features**               | Use bots and Discord features as intended. Do not abuse automation to gain roles, spam channels, or bypass restrictions.                                                         |
| **No NSFW Content**                              | Do not post explicit material, including text, images, or links.                                                                                                                 |
| **Use Appropriate Channels**                     | Keep conversations relevant to channel purpose. Bug reports go in `#bug-reports`, help requests in `#help`, off-topic chat in `#off-topic`.                                      |
| **Discord Voice Chat Etiquette**                 | Avoid loud noises, background music, or mic spam in voice channels.                                                                                                              |
| **Respect @mentions**                            | Do not abuse @everyone, @here, or staff roles without permission.                                                                                                                |
| **No Piracy or Cracked Software**                | Do not ask for, share, or link to pirated software, license keys, cracked tools, or leaked code.                                                                                 |
| **Redact Secrets Before Posting**                | Never paste real API keys, tokens, passwords, or personal data in any channel or GitHub thread. If you paste one by accident, rotate the key immediately and notify a moderator. |
| **Respect Licenses and Attribution**             | Respect the license of any code, script, or asset you share. Do not remove copyright headers or relicense other people's work.                                                   |
| **No Unsolicited DMs**                           | Ask in a public channel first. If someone asks you to stop DMing them, stop.                                                                                                     |
| **No Brigading or Harassment of Other Projects** | Do not use this server to organise raids, review bombing, or harassment against other people or projects.                                                                        |
| **Keep Discussions Constructive**                | Critique code and ideas, not people. "This has a bug on line 42" is fine. "This is garbage" is not.                                                                              |
| **No Leaking Private Repositories**              | Do not share code, credentials, or discussions from private repositories without permission.                                                                                     |
| **Follow GitHub's Community Guidelines**         | When interacting with repositories, follow GitHub's guidelines as well as these rules.                                                                                           |

---

### Community Roles and Access

Moderators are trusted members who help keep the server running. They can mute,
kick, or ban, and their decisions are final unless you escalate to the server
owner. Do not argue with moderator decisions in public channels. If you think a
decision was wrong, message the owner directly.

Contributors are members who have had a pull request merged. This is a vanity
role, not a permission level. It marks people who have actually shipped
something.

Bots are managed automatically. Do not add unofficial bots to the server
without asking first.

## Tiered Punishment System

To ensure fairness, we use a **tiered punishment system**. Consequences are
determined by the severity of the offense and are at the discretion of the
issuing moderator.

### Tier 1: Severe Offenses - Permanent Ban

| Offense                              | Description                                                                      |
| ------------------------------------ | -------------------------------------------------------------------------------- |
| **Malicious Activity**               | Distributing malware, phishing links, or attempting to compromise other members. |
| **Piracy**                           | Sharing or requesting cracked software, license keys, or leaked code.            |
| **Threats and Harassment**           | Making threats or engaging in targeted harassment.                               |
| **Discriminatory Behavior**          | Promoting hatred or discrimination through language or actions.                  |
| **Privacy Violations**               | Sharing personal information without consent.                                    |
| **NSFW Content**                     | Distributing explicit content in any channel or DM.                              |
| **Impersonation of Staff or Server** | Pretending to be a moderator or representing yourself as the server.             |
| **Raid Coordination**                | Using the server to coordinate raids against other communities.                  |
| **Scamming**                         | Deliberately misleading people about paid work, commissions, or services.        |

### Tier 2: Moderate Offenses - 1 to 2-Week Ban

| Offense                           | Description                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------- |
| **Repeated Harassment**           | Sustained trolling, spamming, or ignoring moderator instructions.                        |
| **Abusive Communication**         | Using disrespectful language or targeted insults.                                        |
| **Inappropriate Content**         | Sharing offensive images, memes, or usernames.                                           |
| **Alt Account Evasion**           | Using alternate accounts to bypass a mute or ban.                                        |
| **Bot or Feature Abuse**          | Misusing bots or Discord features to disrupt the server.                                 |
| **Sharing Another Member's Work** | Reposting someone's code, art, or writing without credit or permission.                  |
| **Brigading Other Projects**      | Organising or participating in coordinated harassment against another person or project. |

### Tier 3: Minor Offenses - Warning or Up to 1-Week Mute

| Offense                        | Description                                                               |
| ------------------------------ | ------------------------------------------------------------------------- |
| **Unwanted Communication**     | Sending unsolicited DMs or spamming irrelevant messages.                  |
| **Off-Topic Discussions**      | Excessive off-topic messages or derailing conversations.                  |
| **Voice Chat Etiquette**       | Mic or voice channel misuse, including soundboard spam.                   |
| **Minor @mention Abuse**       | Overusing pings or tagging people unnecessarily.                          |
| **Ignoring Redaction Advice**  | Posting secrets after being asked to redact them.                         |
| **Repeated Low-Quality Posts** | Flooding channels with noise, low-effort questions, or duplicate threads. |

---

## Subsequent Offenses

Repeated violations **on any platform** will result in **escalating
consequences**. For example, a Tier 3 offense on Discord after a prior
GitHub warning may escalate to a Tier 2 penalty.

---

## Cross-Platform Conduct

Behaviour on GitHub and on Discord is linked. If you are removed from the
Discord server for serious misconduct, do not expect to continue interacting
with my repositories through other channels, and I may block your account on
GitHub. Similarly, sustained abuse on GitHub may result in removal from the
Discord server.

The reverse is not true. Being blocked on GitHub by a maintainer, or having an
issue closed, is not grounds for removal from Discord. Those are normal parts
of open-source work.

---

## Undocumented Offenses

While this list provides clear guidelines, members may still be penalised for
**unlisted offenses**. Moderators will consider the **severity and intent** of
the behaviour when enforcing rules, including cross-platform violations such as
coordinating harassment via Discord DMs.
